# Load index explained

> Synthetic knowledge base written for this demo; not official manufacturer guidance. Always follow your vehicle handbook and a qualified tyre professional.

The load index is the number in the service description after the size, for example 91 in 205/55 R16 91V. It is a code for the maximum load one tyre can carry at the correct pressure: 91 means 615 kg, 94 means 670 kg. A replacement tyre must have a load index equal to or higher than the one specified for the vehicle; a lower load index is not acceptable because the tyre could be overloaded.
